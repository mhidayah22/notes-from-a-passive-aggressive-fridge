## The note

> The ice maker has made 312 cubes this week. You have used four. At this rate I will be an ice sculpture by Christmas.

One line, 117 characters. `main.py` writes it to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (then `/output` when it exists, then the folder holding the program).

## Run it

```sh
python3 main.py
```
